# Slides Folder Structure

This folder contains presentation slides organized by chapter.

## Folder Structure:
- `01-introduction/` - Introduction and welcome slides
- `02-services/` - Our services and wellness solutions slides
- `03-programs/` - Health programs and specialized wellness slides
- `04-team/` - Success stories and expert team slides
- `05-join/` - Get started and community slides

## Supported Formats:
- PNG images
- PDF files

## File Naming Convention:
Use sequential numbering for slides within each chapter:
- `slide-01.png`
- `slide-02.png`
- `slide-03.pdf`
etc.
